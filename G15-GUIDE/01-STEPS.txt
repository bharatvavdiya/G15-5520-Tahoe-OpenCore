RESULT SO FAR
  - Mode A WORKS (19 Nov): Iris Xe, Metal 2, 1536 MB, 1920 x 1080 @ 120 Hz, no GPU errors,
    and the session ended normally after 26 minutes. Metal 2 is the maximum for Iris Xe.
  - The old freezes are explained: one was a real crash caused by NullMoth's drivers (a
    NullMoth boot setting made it look like a freeze); the others came from NullMoth or from
    the old 0.8.2 setup (mode C). None of that is on the system any more.
  - A2 test (20 Nov): stable, including the 10-minute CPU test with graphics on. The icon
    placeholders were a one-time cache build (confirmed). Bluetooth works.
  - No sound: macOS 26 removed Apple's audio driver, so the built-in speakers have no driver.
    CONFIRMED (20 Nov): YouTube's "An error occurred" in Safari happens when macOS has no
    sound output. With a Bluetooth soundbar selected, YouTube plays. Bluetooth audio works.
  - D test (21 Nov): macOS no longer saw the RTX 3050 and D ran 41 minutes normally. Then
    the whole Mac froze while you changed the wallpaper. No crash was recorded and the
    logs show no error: they simply stop. The "Tahoe Dark" wallpaper plays a video, and
    the freeze came right after the Wallpaper settings opened again, so the most likely
    cause is the Iris Xe driver stalling on that work (its video decoder or one of its GPU
    engines; the logs cannot tell which). A minute earlier the switch TO Tahoe Dark did
    not freeze; reopening the settings while it ran froze the first time. D's change is
    not ruled out. The grey was never saved, so the Tahoe wallpaper would start again:
    PART 12 changes it first.
  - Wallpaper rule: "do not change it" is only TEMPORARY, not the solution. PART 13 tests
    whether changing the wallpaper freezes the official driver in A. If it does, the logs
    of the freeze decide the fix to test in PART 14: a test build that turns off the GPU's
    compute engine (CCS, on the USB as TEST 7 and TEST 8), or one that turns off the
    hardware video decoder (Claude builds it if needed). The WhateverXe developer has not
    released a fix for this yet.
  - Lab check (22 Nov): 84.3 GB free next to macOS, and Apple still offers the 26.7.3
    installer, so the NVIDIA lab fits. Nothing was created.
  - Shut Down stalled on 20 and 22 Nov. Cause: about 2 minutes after every start, macOS's
    own NetBIOS service connects by itself to a device on your network called "REALTEK"
    (probably the router), and macOS's network-share code loops while shutting down.
    Nothing is mounted, so there is nothing to eject. It is not a graphics freeze:
    see IF IT HANGS step 0.

PART 15 - NVIDIA MODE  (an extra option; any time, it does not depend on PART 13)
  What it is: the BIOS sends the screen to the RTX 3050 (graphics NVIDIA-only, Hybrid
  OFF), and a second macOS called "NVIDIA" on the internal disk runs NullMoth's driver
  3.1 on it (Metal 3). Your normal macOS ("macintosh") and modes 1-8 stay as they are.
  Honest limits (from NullMoth's own pages, 26 Nov):
  - RTX 30 laptops are still "validation pending" there. Another G15 5520 with the same
    RTX 3050 reported 3.0 working on an external monitor, on macOS 15 Sequoia; the
    built-in screen in NVIDIA-only mode on Tahoe is not confirmed on a G15 yet.
  - On a G15 with an RTX 3060 the desktop costs WindowServer 13-14 ms of CPU per frame
    (NullMoth #456, open), so it may not feel smoother than Iris Xe.
  - Brightness often does not change on such laptops in NVIDIA-only mode (known limit).
  - Battery drains faster (the RTX stays on). No sleep, as in all modes.
  - NullMoth needs AMFI off and SIP 0xA43. Only the "NVIDIA" macOS gets them: mode 9
    hides "macintosh" from its menu (step 9).
  - Never use the 1401 app: it rewrites the OpenCore config on this USB.
  Time: about 2-3 hours (17 GB download, then the install). Charger and Ethernet in. The
  BIOS stays on Hybrid until step 11.
  A. Prepare, in your normal macOS:
  1. G15-SWITCH-MODE.bat -> 2 (MAINTENANCE). F12 -> USB -> OpenCore -> "macintosh".
     Open Terminal and run (adds an empty volume "NVIDIA"; nothing is erased):
         sudo bash /Volumes/1401/G15-GUIDE/15-nvidia-lab.sh volume
  2. Download macOS 26.7.3 from Apple (about 17 GB, never 27); it also checks the version:
         sudo bash /Volumes/1401/G15-GUIDE/15-nvidia-lab.sh installer
  3. Run (without sudo; it checks, then opens Apple's installer):
         bash /Volumes/1401/G15-GUIDE/15-nvidia-lab.sh install
     In the installer: Continue > Agree > Agree > "Show All Disks..." > select "NVIDIA"
     (NOT "macintosh") > Continue > your password. The Mac restarts by itself several
     times. At every OpenCore menu choose "macOS Installer", later "NVIDIA", never
     "macintosh", until the setup screens appear.
  B. Set up the NVIDIA macOS (still MAINTENANCE, BIOS still Hybrid):
  4. Setup screens: language, a local user account. Skip Apple Account and iCloud for
     now. Do not turn on FileVault. Then System Settings > Users & Groups > "Automatically
     log in as" > your user (avoids the lock-screen crash some NVIDIA laptops had).
  5. Open Terminal and run:
         sudo bash /Volumes/1401/G15-GUIDE/06-test-mode.sh
     System Settings > General > Software Update > (i) next to Automatic Updates: turn
     off "Download new updates when available" and "Install macOS updates". System
     Settings > Lock Screen: "Require password after screen saver..." -> Never.
  6. Install the driver (the script refuses on "macintosh" and checks the package):
         sudo bash /Volumes/1401/G15-GUIDE/15-nvidia-lab.sh nullmoth
     It downloads NVIDIA's firmware (about 550 MB). When it says DONE: Apple menu >
     Restart, choose "NVIDIA". Then System Settings > Privacy & Security: if an "Allow"
     button for the new extensions is shown, click it and restart once more ("NVIDIA").
  7. Run:
         bash /Volumes/1401/G15-GUIDE/15-nvidia-lab.sh check
     Want "READY for the NVIDIA start: yes" (the driver stays off in MAINTENANCE; that
     is normal). If it says NO: Privacy & Security > Allow, restart, check again; still
     NO: stop and tell Claude "NV not ready".
  8. Still in "NVIDIA": System Settings > General > Startup Disk > select "macintosh" >
     Restart. At the OpenCore menu choose "macintosh" (MAINTENANCE).
  9. In "macintosh" run (hides "macintosh" only from mode 9's menu, so NVIDIA mode can
     never start your normal macOS; all other modes still show it):
         sudo bash /Volumes/1401/G15-GUIDE/15-nvidia-lab.sh hide
     Apple menu > Shut Down.
  C. First NVIDIA start:
  10. In Windows: G15-SWITCH-MODE.bat -> 9 (NVIDIA). G15-CHECK-USB.cmd (click Yes): it
     must end with "Next macOS start uses: NVIDIA (...)". If Windows uses BitLocker or
     device encryption, have the recovery key ready first (a BIOS change can ask for it).
  11. Restart, press F2 for the BIOS and set graphics to NVIDIA-only (Hybrid OFF, the
     setting you set to Hybrid for Iris Xe). Save. F12 -> USB -> OpenCore: the menu waits
     in this mode; choose "NVIDIA". The first start can stop for 1-3 minutes at "PCI
     configuration end": wait; hold the power button only after 5 minutes.
  12. Log in. Open Terminal and run both:
         bash /Volumes/1401/G15-GUIDE/15-nvidia-lab.sh check
         sudo bash /Volumes/1401/G15-GUIDE/02-check.sh
     Want: "MODE: NVIDIA", the NullMoth kexts loaded (NVRM, NVAccel, NVRMFB, NVRMAGDC,
     usually NMXAudio too), "Chipset Model: NVIDIA GeForce RTX 3050" and Metal 3 (or
     newer). Try the brightness keys (no change = the known limit). Use it 15 minutes.
     Apple menu > Shut Down, start Windows and tell Claude: "NV report".
  If the screen stays black or the Mac restarts in a loop (NullMoth's own guard also
  turns its driver off after two failed starts):
  - Hold the power button. In the BIOS set graphics to Hybrid again. In Windows run
    G15-CHECK-USB.cmd (click Yes) and G15-SWITCH-MODE.bat -> 2 (MAINTENANCE).
  - Start "NVIDIA" (in MAINTENANCE) first and run, before anything else:
         sudo bash /Volumes/1401/G15-GUIDE/08-freeze-logs.sh 24
    Then tell Claude "NV black".
  BACK TO IRIS XE (any time): BIOS graphics -> Hybrid, G15-SWITCH-MODE.bat -> 3 (or 2),
  choose "macintosh". The Mac installer and Recovery need a Hybrid mode too (they show
  nothing in mode 9).

WHAT THIS LAPTOP CAN AND CANNOT DO IN macOS (checked against Apple and WhateverXe docs)
  - Iris Xe: Metal 2, the level Apple's Iris Xe driver provides. Metal 4 needs Apple
    silicon (M1 or newer); Apple never made a Metal 3 driver for Iris Xe.
  - RTX 3050: Apple has no driver for RTX 20/30/40 cards. In the Iris Xe modes it is
    unused (mode D hides it; PART 5 step 4 plus the same check in A shows whether it is
    also powered off), so HDMI, which is wired to it, gives no picture there. The
    community driver NullMoth can run it in NVIDIA mode (PART 15, a second macOS with
    AMFI off). It keeps working fully in Windows.
  - CPU: all 12 cores run with Apple's power management. Hyper-Threading stays off: with
    it on, this exact CPU is reported to hang at start, and it gives no speed-up for the UI.
  - Speakers: macOS 26 removed the Apple audio driver that AppleALC needs, so the built-in
    speakers cannot work for now. Use USB or Bluetooth audio.
  - Sleep: the firmware has no S3 sleep, so keep the Mac awake and use Shut Down.


DO NOT

  - TEMPORARY, until Claude updates it after your W report: change the wallpaper and

  - No Apple menu > Lock Screen and no Control-Command-Q: they start the screen saver.

PART 8 - WI-FI WITH HELIPORT  (skipped: Ethernet is used; kept here for later)
  Your EFI already loads the official Intel Wi-Fi driver (itlwm); only its app is missing.
  Wi-Fi then shows up in macOS as an extra "Ethernet", and you join networks from the
  HeliPort icon in the menu bar. No AirDrop or Handoff with this method.
  1. Finder > 1401 (the USB) > G15-GUIDE > downloads > open HeliPort-1.5.0.dmg.
     Drag HeliPort onto Applications, then eject the dmg.
  2. Open HeliPort from Applications. If macOS blocks it: System Settings > Privacy &
     Security > Open Anyway.
  3. Unplug the Ethernet cable. Click the HeliPort icon in the menu bar > Turn Wi-Fi On >
     choose your network (best: 5 GHz, visible name, WPA2) > password > Join >
     Always Allow.
  4. In Terminal (must print an IP address such as 192.168.x.x):
         ipconfig getifaddr en0
     Then open a few websites. If there is no IP: System Settings > Network > the new
     "Ethernet" service for en0 must be set to Using DHCP.
  5. Start HeliPort automatically: System Settings > General > Login Items & Extensions >
     + > Applications > HeliPort > Add.
  6. Check graphics and Bluetooth are unchanged:
         sudo bash /Volumes/1401/G15-GUIDE/02-check.sh
  7. Apple menu > Shut Down. Start Windows and tell Claude: "wifi report".
  Do NOT use any tool that "root patches" macOS (OpenCore Legacy Patcher, OCLP-Mod,
  kgp AirportItlwm-Tahoe): it rebuilds the driver collection that holds the Iris Xe
  graphics and can remove the graphics driver at the next macOS update.
