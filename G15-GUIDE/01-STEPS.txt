PART 7 - VIDEO AND SOUND  (done 20 Nov: with a sound output selected, Safari YouTube plays)
  1. Start A and log in. Give macOS a sound output: pair Bluetooth headphones or a speaker
     (System Settings > Bluetooth), or plug in a USB headset / USB sound adapter. Then
     System Settings > Sound > Output: select it.
  2. Safari > Quit Safari, open Safari again, play the same YouTube video.
     Note: does it play now, or the same error?
  3. Only if it still shows the error: open /Volumes/1401/G15-GUIDE/10-youtube-test.txt
     in TextEdit and follow it.
  4. Smoother scrolling (normal macOS settings, easy to undo):
     System Settings > Accessibility > Display > Reduce transparency: ON
     System Settings > Wallpaper: choose a still picture (not an Aerial video)
  5. Watch videos in a window or YouTube's theater mode, not full screen, and turn off
     System Settings > General > AirDrop & Continuity > AirPlay Receiver
     (both are known WindowServer crash triggers with this graphics driver).
  6. Optional, Google Chrome for video: type chrome://flags, search "Skia Graphite",
     set it to Disabled, click Relaunch.
  7. Apple menu > Shut Down. Start Windows and tell Claude: "video report"
     (did Safari play with sound selected? does scrolling feel better?).


PART 8 - WI-FI WITH HELIPORT  (skipped: Ethernet is used; kept here for later)
  Your EFI already loads the official Intel Wi-Fi driver (itlwm); only its app is missing.
  Wi-Fi then shows up in macOS as an extra "Ethernet", and you join networks from the
  HeliPort icon in the menu bar. No AirDrop or Handoff with this method.
  1. Finder > 1401 (the USB) > G15-GUIDE > downloads > open HeliPort-1.5.0.dmg.
     Drag HeliPort onto Applications, then eject the dmg.
  2. Open HeliPort from Applications. If macOS blocks it: System Settings > Privacy &
     Security > Open Anyway.
  3. Unplug the Ethernet cable. Click the HeliPort icon in the menu bar > Turn Wi-Fi On >
     choose your network (best: 5 GHz, visible name, WPA2) > password > Join >
     Always Allow.
  4. In Terminal (must print an IP address such as 192.168.x.x):
         ipconfig getifaddr en0
     Then open a few websites. If there is no IP: System Settings > Network > the new
     "Ethernet" service for en0 must be set to Using DHCP.
  5. Start HeliPort automatically: System Settings > General > Login Items & Extensions >
     + > Applications > HeliPort > Add.
  6. Check graphics and Bluetooth are unchanged:
         sudo bash /Volumes/1401/G15-GUIDE/02-check.sh
  7. Apple menu > Shut Down. Start Windows and tell Claude: "wifi report".
  Do NOT use any tool that "root patches" macOS (OpenCore Legacy Patcher, OCLP-Mod,
  kgp AirportItlwm-Tahoe): it rebuilds the driver collection that holds the Iris Xe
  graphics and can remove the graphics driver at the next macOS update.


PART 6 - LONGER TEST OF A  (done 20 Nov)
  In Windows first:
  1. Open the USB in File Explorer, double-click G15-CHECK-USB.cmd, click Yes.
     It must end with "RESULT: ..." and "Next macOS start uses: A".
  In macOS (Ethernet cable and charger plugged in, USB mouse, lid open):
  2. F12 -> USB -> OpenCore -> your macOS disk. Do NOT select Reset NVRAM.
  3. Log in, open only Terminal, wait 5 minutes without touching anything.
  4. Measure (2 minutes, do not touch the laptop):
         sudo bash /Volumes/1401/G15-GUIDE/09-perf-check.sh quick
  5. Measure while icons load:
         sudo bash /Volumes/1401/G15-GUIDE/09-perf-check.sh watch
     When it says NOW: open System Settings and click 3-4 items. When it says Saved:
     quit System Settings (Cmd+Q), open it again, and note: were the icons instant now?
  6. Stop Spotlight from writing to the USB, then check (must say "Indexing disabled"):
         sudo mdutil -i off /Volumes/1401
         mdutil -s /Volumes/1401
  7. System Settings > General > Software Update > (i) next to Automatic Updates:
     turn OFF "Download new updates when available" and "Install macOS updates".
  8. Use the Mac for about an hour: Finder, Safari, a 10-minute 1080p YouTube video, and
     try the brightness keys once. If only the video stalls, wait 60 seconds.
  9. Quit Safari (Cmd+Q). CPU test with graphics on (10 minutes; do not use the laptop,
     only tap Caps Lock once a minute and watch its light):
         bash /Volumes/1401/G15-GUIDE/07-cpu-test.sh
 10. Check the disk (only reads, usually 1-5 minutes). Close other apps first. While it
     runs, apps may pause; that is normal, not a freeze: do not touch the laptop and wait
     up to 15 minutes for the last line "Finished file system verification ...". A few
     lines above it, it must say "appears to be OK" and "exit code is 0":
         sudo diskutil verifyVolume /System/Volumes/Data
 11. Full check:
         sudo bash /Volumes/1401/G15-GUIDE/02-check.sh
 12. Apple menu > Restart (not the power button). Start A again, log in, open only
     Terminal, wait 5 minutes, then repeat steps 4 and 5.
 13. Apple menu > Shut Down. Start Windows and tell Claude: "A2 report".

  4. F12 -> Windows Boot Manager. On the USB, double-click G15-CHECK-USB.cmd (click Yes),
     then G15-SWITCH-MODE.bat -> choose 2 (MAINTENANCE normal).

         sudo bash /Volumes/1401/G15-GUIDE/08-freeze-logs.sh
     Then start Windows and tell Claude: "check logs".


WHAT THIS LAPTOP CAN AND CANNOT DO IN macOS (checked against Apple and WhateverXe docs)
  - Iris Xe: Metal 2, the level Apple's Iris Xe driver provides. Metal 4 needs Apple
    silicon (M1 or newer); Apple never made a Metal 3 driver for Iris Xe.
  - RTX 3050: no macOS driver exists for RTX 20/30/40 cards. Mode D switches it off in
    macOS; it keeps working fully in Windows. HDMI is wired to it, so no HDMI in macOS.
  - CPU: all 12 cores run with Apple's power management. Hyper-Threading stays off: with
    it on, this exact CPU is reported to hang at start, and it gives no speed-up for the UI.
  - Speakers: macOS 26 removed the Apple audio driver that AppleALC needs, so the built-in
    speakers cannot work for now. Use USB or Bluetooth audio.
  - Sleep: the firmware has no S3 sleep, so keep the Mac awake and use Shut Down.


DO NOT
  - No Apple menu > Sleep, no closing the lid, no "Put Display to Sleep" hot corner.
  - No Photos app, no Live Text on pictures (GPU hang triggers reported on Iris Xe).
  - No cleaner apps, no icon-cache tricks, no Safe Mode "to clear caches".
  - Do not open the 1401 app and do not install anything from NullMoth or AppleALC.
  - Do not Reset NVRAM, do not install macOS updates, never macOS 27.
