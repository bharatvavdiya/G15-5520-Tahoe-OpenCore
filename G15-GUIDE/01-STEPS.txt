RESULT SO FAR
  - Mode A WORKS (19 Nov): Iris Xe, Metal 2, 1536 MB, 1920 x 1080 @ 120 Hz, no GPU errors,
    and the session ended normally after 26 minutes. Metal 2 is the maximum for Iris Xe.
  - The old freezes are explained: one was a real crash caused by NullMoth's drivers (a
    NullMoth boot setting made it look like a freeze); the others came from NullMoth or from
    the old 0.8.2 setup (mode C). None of that is on the system any more.
  - A2 test (20 Nov): stable, including the 10-minute CPU test with graphics on. The icon
    placeholders were a one-time cache build (confirmed). Bluetooth works.
  - No sound: macOS 26 removed Apple's audio driver, so the built-in speakers have no driver.
    CONFIRMED (20 Nov): YouTube's "An error occurred" in Safari happens when macOS has no
    sound output. With a Bluetooth soundbar selected, YouTube plays. Bluetooth audio works.
  - D test (21 Nov): macOS no longer saw the RTX 3050 and D ran 41 minutes normally. Then
    the whole Mac froze while you changed the wallpaper. No crash was recorded and the
    logs show no error: they simply stop. The "Tahoe Dark" wallpaper had just run with
    graphics acceleration for the first time, so the most likely cause is the Iris Xe
    driver stalling on that wallpaper work. D's change is not ruled out yet. The grey was
    never saved, so the Tahoe wallpaper would start again: PART 12 changes it first.
  - Lab check (22 Nov): 84.3 GB free next to macOS, and Apple still offers the 26.7.3
    installer, so the NVIDIA lab fits. Nothing was created.
  - Shut Down stalled on 20 and 22 Nov. Cause: about 2 minutes after every start, macOS's
    own NetBIOS service connects by itself to a device on your network called "REALTEK"
    (probably the router), and macOS's network-share code loops while shutting down.
    Nothing is mounted, so there is nothing to eject. It is not a graphics freeze:
    see IF IT HANGS step 0.

WHAT THIS LAPTOP CAN AND CANNOT DO IN macOS (checked against Apple and WhateverXe docs)
  - Iris Xe: Metal 2, the level Apple's Iris Xe driver provides. Metal 4 needs Apple
    silicon (M1 or newer); Apple never made a Metal 3 driver for Iris Xe.
  - RTX 3050: no macOS driver exists for RTX 20/30/40 cards. Mode D hides it from macOS
    (PART 5 step 4 plus the same check in A shows whether it is also powered off); it
    keeps working fully in Windows. HDMI is wired to it, so no HDMI in macOS.
  - CPU: all 12 cores run with Apple's power management. Hyper-Threading stays off: with
    it on, this exact CPU is reported to hang at start, and it gives no speed-up for the UI.
  - Speakers: macOS 26 removed the Apple audio driver that AppleALC needs, so the built-in
    speakers cannot work for now. Use USB or Bluetooth audio.
  - Sleep: the firmware has no S3 sleep, so keep the Mac awake and use Shut Down.

PART 8 - WI-FI WITH HELIPORT  (skipped: Ethernet is used; kept here for later)
  Your EFI already loads the official Intel Wi-Fi driver (itlwm); only its app is missing.
  Wi-Fi then shows up in macOS as an extra "Ethernet", and you join networks from the
  HeliPort icon in the menu bar. No AirDrop or Handoff with this method.
  1. Finder > 1401 (the USB) > G15-GUIDE > downloads > open HeliPort-1.5.0.dmg.
     Drag HeliPort onto Applications, then eject the dmg.
  2. Open HeliPort from Applications. If macOS blocks it: System Settings > Privacy &
     Security > Open Anyway.
  3. Unplug the Ethernet cable. Click the HeliPort icon in the menu bar > Turn Wi-Fi On >
     choose your network (best: 5 GHz, visible name, WPA2) > password > Join >
     Always Allow.
  4. In Terminal (must print an IP address such as 192.168.x.x):
         ipconfig getifaddr en0
     Then open a few websites. If there is no IP: System Settings > Network > the new
     "Ethernet" service for en0 must be set to Using DHCP.
  5. Start HeliPort automatically: System Settings > General > Login Items & Extensions >
     + > Applications > HeliPort > Add.
  6. Check graphics and Bluetooth are unchanged:
         sudo bash /Volumes/1401/G15-GUIDE/02-check.sh
  7. Apple menu > Shut Down. Start Windows and tell Claude: "wifi report".
  Do NOT use any tool that "root patches" macOS (OpenCore Legacy Patcher, OCLP-Mod,
  kgp AirportItlwm-Tahoe): it rebuilds the driver collection that holds the Iris Xe
  graphics and can remove the graphics driver at the next macOS update.
