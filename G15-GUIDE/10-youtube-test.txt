G15 5520 - YouTube in Safari test (only if YouTube still shows "An error occurred" after
you selected a sound output in System Settings > Sound > Output and restarted Safari).

1. Safari > Settings > Advanced: tick "Show features for web developers". Close Settings.
2. Open the YouTube video in a normal window and wait for "An error occurred". Do not reload.
3. Safari menu bar: Develop > Show JavaScript Console.
4. In THIS file, triple-click the long line below the dashes (it selects the whole line),
   press Cmd+C, click the input line at the bottom of the console, press Cmd+V, then Return.
5. After about 3 seconds one line starting with YTTEST appears (it ends with copied=yes).
   Open TextEdit, press Cmd+V, and save it as yttest.txt on the USB:
   File > Save > choose 1401 > G15-GUIDE > reports.
6. Then in Terminal (Cmd+Space, type Terminal, Enter), WITHOUT sudo:
       bash /Volumes/1401/G15-GUIDE/10-video-log.sh
7. Start Windows and tell Claude: "video report".

The line only reads what Safari and YouTube report (codecs offered, the player error, the
clock). It changes nothing.
